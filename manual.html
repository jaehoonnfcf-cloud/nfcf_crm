🗂️ 고객정보 관리로 돌아가기

고객정보 관리 페이지, 이렇게 쓰세요

버튼 하나하나가 뭘 하는지, 눌렀을 때 어떤 일이 일어나는지 정리했어요. 화면에서 보이는 것과 똑같은 버튼 모양으로 표시했으니, 헷갈리면 여기서 찾아보세요.

🔍 검색

가장 자주 쓰게 될 기능이에요. 화면에 진입해도 처음엔 아무것도 안 보이는데, 이건 데이터가 많아서 미리 다 안 불러오기 때문이에요.

🔍 검색

검색창에 입력 후 이 버튼 클릭 (또는 Enter)

고객번호, 성명, 고객정보 안에 있는 내용까지 한 번에 검색돼요. 예를 들어 고객정보 메모에 "이사"라고 적어뒀으면 "이사"로 검색해도 나옵니다.

🏅 조합원만 보기

조합원 명단에 등록된 고객만 걸러서 보고 싶을 때 켜는 스위치예요.

🏅 조합원만 보기

누르면 진한 색으로 켜짐 (활성화 표시)

켜진 상태에서 검색하거나 "전체고객 보기"를 하면, 조합원인 고객만 나와요. 조합원 명단 자체는 관리자 페이지에서 CSV로 관리됩니다. 🧹 초기화를 누르면 이 필터도 같이 꺼져요.

🙋 내 담당 고객

내가 담당자로 지정된 고객만 모아서 보는 화면이에요.

🙋 내 담당 고객

누르면 내 담당 고객 목록만 표시

담당 고객이 많으면 이 화면에서 페이지 단위로 넘겨볼 수 있어요. 여기서 바로 🤝 접점 버튼으로 활동을 기록할 수도 있습니다.

📋 전체고객 보기

검색 조건 없이 등록된 고객 전체를 페이지 단위로 훑어볼 때 사용해요.

📋 전체고객 보기

표 아래 "100명씩 / 500명씩 / 1000명씩 보기"로 조절 가능

고객 수가 많아서 한 번에 다 부르면 느려지니, 이렇게 페이지로 나눠서 보여드려요. 이전/다음 버튼으로 페이지를 넘길 수 있습니다.

🗑️ 휴지통

삭제한 고객은 완전히 사라지는 게 아니라 여기로 이동해요.

🗑️ 휴지통

삭제된 고객 목록 + ♻️ 복구 버튼

실수로 삭제했어도 여기서 "복구" 누르면 원래대로 되돌릴 수 있어요. 언제, 누가 삭제했는지도 같이 표시됩니다.

🧹 초기화

검색어, 조합원 필터 등을 전부 지우고 처음 상태(대기 화면)로 되돌립니다.

🧹 초기화

화면이 복잡해졌을 때 리셋 용도

데이터를 지우는 게 아니라, 화면 상태만 처음으로 되돌리는 버튼이에요. 안전하게 눌러도 됩니다.

📤 CSV 업로드

엑셀에서 정리한 고객 명단을 한 번에 여러 건 등록/갱신할 때 사용해요.

📤 CSV 업로드

누르면 저장 방법 안내 팝업이 먼저 뜸

엑셀에서 저장할 때 꼭 "CSV UTF-8(쉼표로 분리)"로 저장해야 한글이 안 깨져요.
첫 줄(헤더)에는 고객번호(또는 customer_no), 성명(또는 name), 고객정보(또는 customer_info) 열이 있어야 합니다.

업로드하면 미리보기 화면에서 신규 / 중복 / 휴지통으로 자동 구분돼요.
- 신규는 자동으로 체크되어 바로 추가되고
- 중복/휴지통 건은 기본적으로 체크가 꺼져있고, 건별로 🔗 이어붙이기(기존 내용 뒤에 새 내용 추가) 또는 🔄 덮어쓰기(완전 교체) 중 선택할 수 있어요.
마지막에 "선택 항목 적용"을 눌러야 실제로 반영됩니다.

➕ 고객 추가

한 명씩 직접 등록할 때 사용해요.

➕ 고객 추가

고객번호 · 성명 · 고객정보 입력 후 추가

이미 있는 고객번호를 입력하면 바로 "이미 존재합니다" 경고가 떠요. 휴지통에 있는 번호면 "복구해주세요"라고 안내됩니다.

🙋 담당자 배정

고객 목록 표의 "담당자" 열에서 바로 배정/변경할 수 있어요.

드롭박스에서 담당 직원 선택 → 자동 저장

직원 누구나 자유롭게 배정/변경할 수 있어요. 선택하는 즉시 저장되며, 담당자로 지정되면 그 직원 화면에 🤝 접점 버튼이 나타나고 "내 담당 고객"에도 포함됩니다.

🤝 접점기록

담당 고객과 언제, 어떻게 접촉했는지 남기는 기능이에요. 내가 담당하는 고객에게만 이 버튼이 보여요.

🤝 접점

활동 유형 · 일자 · 내용 입력 후 기록 추가

활동 유형은 자유롭게 입력하시면 돼요 (예: 전화, 방문, 문자/카톡, 마케팅 등). 지금까지 쌓인 접점 기록도 같은 창에서 시간순으로 확인할 수 있어요.

표 안의 버튼들

각 고객 행마다 오른쪽에 있는 작은 버튼들이에요.

💾 저장

성명/고객정보를 수정하면 활성화됨

칸을 고치면 이 버튼이 눌리게 바뀌어요. 눌러야 실제로 저장됩니다 (자동저장 아님).

🕘 이력

이 고객의 등록/수정/삭제 기록 전체 보기

언제, 누가, 무엇을 바꿨는지 이전값→새값 형태로 확인할 수 있어요.

🗑️ 삭제

완전 삭제 아님 — 휴지통으로 이동

실수해도 괜찮아요. 🗑️ 휴지통에서 다시 복구할 수 있습니다.

🏅조합원

성명 옆 배지 — 조합원 명단 등록 여부

이 배지가 붙어있으면 조합원 명단(관리자가 관리)에 등록된 고객이라는 뜻이에요.

📊 나의 활동 카드

로그인하면 맨 위에 항상 보이는 카드들이에요. 새로고침해도 그대로 있고, 등록/수정할 때마다 바로 갱신됩니다.

🆕 오늘 등록3건
✏️ 오늘 수정12건
📊 이번 주 누적41건
🔥 연속 활동일5일째

"연속 활동일"은 매일 최소 한 번 이상 고객정보를 만졌는지를 기준으로 세요. 오늘 아직 아무것도 안 했어도 어제까지 이어온 기록이 있으면 계속 표시되니 걱정 마세요.

⚙️ 관리자 전용 기능

일반 직원 화면에는 안 보이고, 관리자로 지정된 계정에만 헤더에 "⚙️ 관리자" 링크가 나타나요.

관리자 페이지에서는 사용자 관리(직원 추가/삭제), 접속이력, 전체 수정이력, CSV 업로드 이력, 조합원 명단 관리, 담당자/접점활동 현황, 대시보드(오늘 활동, 최근 7일 추이 등)를 확인할 수 있어요. 일반 업무에는 필요 없는 기능들이라 직원 화면에는 노출되지 않습니다.
